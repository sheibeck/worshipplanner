<objective>
R239 part 2 of 2 — add WAI-ARIA APG Tabs semantics to BOTH tab strips (Owner Console's Configuration/Organizations, and the matching ServiceEditorView Service Order/Slides/Roles/Messages strip) without changing their `v-show`-always-mounted panels. Attributes are additive only; the existing `activeTab`/`setTab` reactive state and the router-query deep-link sync stay the single source of truth.

Purpose: The tab strips are plain buttons with zero ARIA, so assistive tech does not announce them as tabs. The critical constraint (RESEARCH Pitfall 4 + the components' own comments) is that panels are `v-show`-mounted so their `onSnapshot` listeners stay live — a generic `v-if` ARIA-tabs pattern would kill those subscriptions. Both strips must be done in one pass (RESEARCH warns this gets done on one and forgotten on the other).
Output: ARIA-annotated tab strips in `OwnerConsoleView.vue` and `ServiceEditorView.vue`, with tests asserting the roles/attributes and a regression test that the panels stay mounted across a tab switch.
</objective>
