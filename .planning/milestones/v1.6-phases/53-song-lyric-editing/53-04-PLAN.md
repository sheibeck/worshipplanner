<objective>
Fix the confusing first-paste button label: on a brand-new song being given lyrics for the first time,
the paste-lyrics commit button should read "Save" instead of "Replace lyrics" (R121). The existing helper
text already explains that a paste replaces the current lyrics.

Purpose: A non-technical user pasting lyrics into an empty song is not "replacing" anything — the
"Replace lyrics" label is confusing on first use. This is a self-contained, one-component change driven by
the prop the component already receives.

Output: `LyricPasteRegion.vue`'s commit button reads "Save" when the song has no sections and
"Replace lyrics" when it does; "Saving..." while a save is in flight (unchanged). Fully independent of the
other Phase 53 plans (different file, no shared model) — runs in Wave 1.
</objective>
