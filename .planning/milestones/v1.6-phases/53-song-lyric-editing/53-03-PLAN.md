<objective>
Make the split, numbering, and Pre-Chorus capabilities visible and authorable in the song lyric editor
(`SongLyricEditor.vue`), the non-technical-user-facing surface. This plan renders Plan 01's derived
numbering, exposes the Pre-Chorus palette entry, and adds the manual click-between-lines split affordance
that writes `slideBreaks`.

Purpose: R117's split is manual-only (AI auto-split is out of scope) — the whole point is a user picks
the break points. This plan delivers that authoring UI plus the R120 numbering display fix (the owner's
"unnamed Verse" bug) and the R119 Pre-Chorus button.

Output: The editor shows position-numbered labels, a Pre-Chorus add button, and a per-line split UI whose
clicks persist `slideBreaks` via the existing autosave. No assembler or model logic is reimplemented here
— the editor is a thin consumer of Plan 01's helpers.

Depends on Plan 01: consumes `SectionRow.displayLabel`, the `slideBreaks` field on `LyricSection`,
`sliceSectionIntoSlides`, and the `'Pre-Chorus'` member of `ADD_SECTION_KINDS`.
</objective>
