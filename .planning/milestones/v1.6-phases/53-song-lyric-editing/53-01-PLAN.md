Establish the pure, framework-free model core Phase 53 is built on, all inside the two pure modules
`src/types/songLyrics.ts` and `src/utils/songSectionOrder.ts` (RED-first unit tests before wiring).

This plan delivers the three pure building blocks the rest of the phase consumes:
- **R117 slicing:** the additive optional `slideBreaks?: number[]` field on `LyricSection`, plus the
  pure `sliceSectionIntoSlides(section)` helper that turns break indices into 1..N line-groups.
- **R120 numbering:** the pure `deriveSectionKind(label)` helper and a per-kind position ordinal
  surfaced as `SectionRow.displayLabel`, fixing the bare-"Verse" bug without rewriting stored labels.
- **R119 Pre-Chorus:** `'Pre-Chorus'` added to `ADD_SECTION_KINDS`.

Purpose: These helpers are the load-bearing seam. Getting them pure and correct here means the
assembler wiring (Plan 02) and the editor UI (Plan 03) are thin consumers, and R118 duplication works
for free (a split lives on ONE pooled section, so a duplicated order reference carries the whole split).

Output / Artifacts this phase produces (introduced here): the `LyricSection.slideBreaks` field, the
`sliceSectionIntoSlides` helper, the `deriveSectionKind` helper + `SectionRow.displayLabel` numbering,
and the `'Pre-Chorus'` kind. Downstream plans wire these into the assembler, editor, and paste button.
