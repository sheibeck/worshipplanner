with the just-shipped Service Order redesign (quick task 260811-vsr): three-rail rows, a colored

plain per-kind headings). This closes that gap so the app reads as one system.

Output: A restyled `ServiceTemplateEditor.vue` and a `kindBadgeClass` helper extracted to
`slotTypes.ts` and shared by both editors. This is restyle + control-relocation ONLY — zero behavior
or data change. `ServiceTemplateEntry` shape is unchanged; every template feature is preserved.
