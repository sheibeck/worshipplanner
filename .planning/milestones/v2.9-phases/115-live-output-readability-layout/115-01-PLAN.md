<objective>
Build the framework-light auto-fit engine every R329 render site will share: a pure, binary-searched text-fit function plus its ResizeObserver composable, and a geometric "contain" scaler for the canonical 1280x720 stage. No consumers are wired yet — this is the highest-leverage, lowest-risk piece (pure functions, unit-tested in isolation) and unblocks the SlideCanvas + output-view integration in Plan 03.

Purpose: Replace the discrete `--slide-font-scale` multiplier (a manual sm/md/lg setting) with a measure-and-fit that grows text to fill and shrinks it to avoid overflow, capped at a sane max — computed once against the canonical slide frame so the identical fit can flow to the Audience + Confidence outputs AND the Run-screen previews/thumbnails.

Output: `src/composables/useSlideAutoFit.ts` exporting `computeFitScale`, `computeContainScale`, `useSlideAutoFit`, `useContainScale`, and the DEFAULT/MAX scale constants — all unit-tested.

MUST stay pure where it counts: the fit math is a pure function driven by an injected "does this scale fit?" oracle (no DOM), so it is deterministic and testable; the ResizeObserver wiring is a thin, feature-detected, never-throws shell that degrades to the identity default where layout is unavailable (jsdom/SSR), exactly as the existing `useScaleToFit` in RunPreviewPair does.
</objective>

## Artifacts this plan produces (new symbols)

- `computeFitScale(fits: (scale: number) => boolean, opts?: { min?: number; max?: number; steps?: number }): number` — NEW. Binary-searches [min, max] for the largest scale where `fits(scale)` is true; returns min when even min fails, max when max fits. Pure, no DOM.
- `computeContainScale(containerW: number, containerH: number, refW: number, refH: number): number` — NEW. Returns `min(containerW/refW, containerH/refH)` clamped to a positive finite number; returns the identity default when any input is non-finite or <= 0. Pure, no DOM.
- `useSlideAutoFit(options?: { max?: number }): { frameRef, contentRef, scale }` — NEW composable. Measures the content element against the frame element and exposes a reactive `scale` (the largest fitting text scale), re-measured on mount, on a `retrigger()` (slide change / font ready), and via a ResizeObserver on the frame. Falls back to DEFAULT_FIT_SCALE where layout is unavailable.
- `useContainScale(options?: { refW?: number; refH?: number }): { containerRef, scale }` — NEW composable. ResizeObserver-driven geometric scale-to-contain of a fixed reference stage inside its container; falls back to 1 where layout is unavailable.
- `DEFAULT_FIT_SCALE = 1` and `MAX_FIT_SCALE` (a sane cap, e.g. 4) — NEW exported constants.
- `REFERENCE_WIDTH = 1280`, `REFERENCE_HEIGHT = 720` — NEW exported constants (the canonical slide frame; the single source Plan 03 imports so the stage size is defined once).
</artifacts>
