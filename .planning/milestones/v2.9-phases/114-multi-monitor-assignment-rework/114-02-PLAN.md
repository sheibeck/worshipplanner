<objective>
Rework the Monitor Setup role-assignment UI so a projectionist can assign any role to any of N monitors — including multiple Audience — with independent per-monitor selection, a None option, per-monitor nicknames, and a delta-aware reprompt that only asks about newly-added displays.

Purpose: Kill the "select Audience on one monitor and it clears on another" bug (a UI/state defect — the data model already supports repeated roles) and replace the all-or-nothing "your monitors changed" reconfigure with a keep-the-matches delta flow. Add nicknames so macOS "Unknown"/numbered displays are identifiable.

Output: A `MonitorCard.vue` with None + nickname affordances and a `MonitorSetupView.vue` whose state is a per-fingerprint role map + nickname map, consuming Plan 01's `computeFingerprints` and delta `matchMapping`.
</objective>
