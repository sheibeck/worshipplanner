<objective>
Rework the pure persistence module `src/utils/monitorConfig.ts` — the framework-free foundation every other Plan in this phase sits on — to fix the two root causes of "roles don't stick on 3 monitors" and the false "monitors changed" reprompt (R326/R328), and to add the per-monitor nickname data model (R338).

Purpose: A stable, delta-aware identity/persistence model that no longer discards a whole mapping when one monitor changes, and never reshuffles identity from volatile macOS position/primary drift. This is the highest-leverage, lowest-risk change (pure module, unit-tested in isolation) and unblocks all Wave 2 plans.

Output: v2 fingerprint (`label:WxH` identity + stable sorted-position disambiguation index), a delta-aware `matchMapping` returning matched/partial/no-mapping, a `nickname` field on `MonitorAssignment`, hardened `isValidMapping`, a bumped storage key, and the shared `SCREEN_QUERY_PARAM` contract constant.

MUST stay pure / never-throws / localStorage-only per ADR-0183 and ARCHITECTURE.md Anti-Pattern 3 — no Vue, Firebase, or Pinia imports.
</objective>

## Artifacts this plan produces (new/changed symbols)

- `computeFingerprints(screens: ScreenLike[]): Map<ScreenLike, string>` — NEW. Groups by identity key `label:WxH`, sorts each group by `(left, top)`, assigns a 0-based `#index` within the group.
- `computeFingerprint(screen: ScreenLike, allScreens?: ScreenLike[]): string` — CHANGED signature. Second arg optional and backward-compatible: absent → the screen is treated as its own single-member group (`#0`); present → the correct group index is computed.
- `MatchResultV2` — NEW union: `{ status: 'matched' } | { status: 'partial'; kept: MonitorAssignment[]; newScreens: ScreenLike[] } | { status: 'no-mapping' }`.
- `matchMapping(saved, liveScreens): MatchResultV2` — CHANGED return type (delta-aware). The `'needs-reprompt'` literal is retired.
- `MonitorAssignment.nickname?: string` — NEW optional field.
- `MONITOR_CONFIG_STORAGE_KEY` — CHANGED value `wp:runMonitorConfig:v2`.
- `SCREEN_QUERY_PARAM = 'screen'` — NEW exported constant (opener->popup fingerprint-hand-off contract for Plans 03/04).
- `NICKNAME_MAX_LENGTH` — NEW exported constant (cap used by `isValidMapping`).
