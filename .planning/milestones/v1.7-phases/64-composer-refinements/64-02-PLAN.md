| Client → server token render | The client never sends resolved names for substitution — the server re-derives `target.name` from the authoritatively re-resolved recipient list (Phase 58/59). The client sample render (64-03) only mirrors this for preview |
| npm registry → functions build | No package installed — an additive interface field + one substitution line + test edits. Zero supply-chain surface |
