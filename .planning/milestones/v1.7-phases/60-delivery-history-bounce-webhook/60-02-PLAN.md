<objective>
Build the milestone's new unauthenticated trust boundary: the `messageWebhook` `onRequest` HTTP Function that
receives Resend's delivery/bounce events, verifies the Svix HMAC over the RAW body BEFORE any Firestore access,
and — only on a valid signature and a hard (`Permanent`) bounce — idempotently flips the addressed
`recipients/{id}` to `status:'bounced'` and increments `messages/{id}.deliveryCounts.bounced`.

Purpose: R143 (surface hard bounces) and ROADMAP success criteria 3 (verify-first, zero-write on bad signature)
and 4 (duplicate delivery = safe no-op, never a double count). This is the phase's security-critical surface —
every branch is tested explicitly. The handler mirrors the `api` onRequest wrapper shape
(`functions/src/index.ts:140`) but, unlike `api` (a byte-lossy pass-through proxy that re-serializes `req.body`),
the HMAC is computed over `req.rawBody` — the raw received bytes are load-bearing (60-CONTEXT.md :41-44).

Depends on 60-01: imports `verifySvixSignature` from `./webhookSignature` and relies on the deploy-gated
`recipients.providerMessageId` collection-group index for the addressing fallback.

DEPLOY-GATED (v1.7 grant): `messageWebhook` ships built/tested/UNDEPLOYED against a MOCKED secret and a
hand-computed valid signature. No secret set, no deploy, no Resend dashboard config — all handed to the owner.

Output: `RESEND_WEBHOOK_SECRET`, the exported helpers `resolveRecipientRef` + `recordBounce`, the exported
`messageWebhookHandler`, and the secret-bound `messageWebhook` wrapper in `functions/src/index.ts`, plus new
describe blocks (with an extended `getFirestore` fake) in `functions/src/index.test.ts`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet (anyone) → messageWebhook (onRequest) | The milestone's new UNAUTHENTICATED boundary; a forgeable webhook is a live Firestore write hole. Only the Svix HMAC over req.rawBody, verified before any state access, gates it |
| messageWebhook → Firestore (Admin SDK) | The webhook is the sole writer of status:'bounced' + deliveryCounts.bounced; rules deny all client writes here (firestore.rules :144,152) |
| Retried delivery (at-least-once) | Resend retries on non-2xx and may deliver the same event twice; a duplicate must be a safe no-op on the count |
| RESEND_WEBHOOK_SECRET (Secret Manager) | Distinct from RESEND_API_KEY; bound only to messageWebhook, never in the client bundle or .env.local |
