<objective>
Rewire the slideshow assembler's two IMPORTED paths onto the shared reconciler, so the presenter and
the grid resolve identical content from identical inputs, and so a pending or failed slide is a
present, non-drawable slide rather than an absent one.

Implements D-05 (`renderedCount` wins), D-06 (parsed text never drawn), D-07 (surplus rendered pages
emitted, not dropped), D-08 (one shared helper, both consumers) and D-16 (no `renderImportId` → the
untouched parsed path).

Purpose: `assembleSlideshow` has an `if (!content) continue` that omits any entry whose source no
longer resolves. That is correct for a deleted song section and catastrophic for a pending render —
it would silently shorten the deck mid-service, which 42-UI-SPEC.md calls non-negotiable. The
reconciler already returns a defined object for every state; this plan makes the assembler consume
it on both paths.

Output: two rewired branches and new coverage in an 1,817-line test file.
</objective>
