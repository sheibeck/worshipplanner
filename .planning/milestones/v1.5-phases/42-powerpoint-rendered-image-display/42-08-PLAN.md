## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| render document → Storage read volume | `renderedCount` drives how many `getDownloadURL` calls the browser issues |
| render document → group document write | a render transition triggers a Firestore write to persisted user data |
| long-lived browser session → Firestore listener pool | a projection machine may hold this page open across an entire service |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-42-06 | Denial of Service | render-listener lifecycle | low | mitigate | Listeners accumulating across service navigations exhaust connections in a long session. Mitigated by driving `syncSubscriptions` off a computed id set that shrinks as well as grows, and by `unsubscribeAll()` in `cleanup()`; asserted by Task 1's spy assertions. |
| T-42-07 | Spoofing | stale render page array served under a re-imported deck | high | mitigate | A re-render or re-import that changes the page count must never serve the previous render's URLs. Asserted by Task 2 criterion (c). |
