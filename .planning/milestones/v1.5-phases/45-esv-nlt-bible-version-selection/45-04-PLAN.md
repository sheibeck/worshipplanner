## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authStore.settings -> fetch routing | The current org setting selects the fetch source and is captured as per-slide provenance at fetch time |
| slide.translationSource -> render | The slide's own (or field-less fallback) provenance drives the displayed attribution — not the current setting |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-41 | Tampering (retroactive attribution flip) | render sites (PresentationViewer, slideDisplay) | high | mitigate | Attribution is driven by `resolveTranslationSource(slide)` (the stamped/field-less value), never the org's current setting — a later setting change cannot alter an existing slide's shown attribution. Asserted with a field-less->(ESV) test. |
| T-45-42 | Tampering (mis-stamp / restamp) | CongregationalEditor stamping | medium | mitigate | translationSource captured ONCE at fetch time from the setting; downstream never re-derives; a post-fetch setting change does not restamp existing sections (test-asserted). |
| T-45-43 | Consistency (duplicate attribution logic) | both render sites | low | mitigate | Both sites consume the single shared `scriptureAttribution` helper (R091 build-once); no inline duplicate string permitted. |
| T-45-44 | Tampering (HTML injection via rendered text) | PresentationViewer paragraphs | low | mitigate | Suffix and passage render as text interpolation ({{ }}), not v-html; parsed NLT text is already plain textContent (45-01). No markup executes. |
