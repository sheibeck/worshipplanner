<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Firebase Storage | Untrusted browser uploads/downloads cross into org-scoped Storage objects. |
| Storage rules → Firestore | Storage rule evaluates a cross-service Firestore read to resolve org membership. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-02-01 | Information Disclosure | Cross-org read of another org's Storage objects | high | mitigate | storage.rules read gate requires a firestore.exists membership lookup keyed by request.auth.uid under the same orgId prefix; proven by the non-member deny test. |
| T-21-02-02 | Elevation of Privilege | Non-member writing into an org's Storage prefix | high | mitigate | storage.rules write gate uses the identical membership condition; proven by the non-member deny test. |
| T-21-02-03 | Denial of Service | Oversized upload consuming Storage/cost | medium | mitigate | 25 MB request.resource.size cap on write, proven by the over-cap deny test; a server-side backstop is added in 21-04. |
</threat_model>
