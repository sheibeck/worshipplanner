<planner_assumptions>
1. **The CTA's disabled guard needs no new prop.** `23-PATTERNS.md` flagged that the CTA state is
   specified against `assembledSlideshow.length === 0` while `SlideshowPreview` only receives
   `sections`, and asked the planner to verify equivalence. **Verified** against
   `src/composables/useSlideshowAssembly.ts` lines 173-191: `assembledSections` partitions EVERY
   slide into a named `SERVICE_SECTIONS` group or the trailing `Ungrouped` group, so the total slide
   count across `nonEmptySections` is always exactly `assembledSlideshow.length`. The existing
   `hasAnySlides` computed is therefore an exact equivalent, and no new prop is added.

2. **PresentationViewer is mounted from `ServiceEditorView`, not from inside `SlideshowPreview`.**
   The viewer already teleports itself to `body`, so no `<Teleport>` wrapper is added at the call
   site, and the `presenting` state lives in the view that owns the service — keeping
   `SlideshowPreview` purely presentational, consistent with how it is written today.
</planner_assumptions>
