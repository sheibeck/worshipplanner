<objective>
Extend the Phase 22 media players with the two capabilities the presentation viewer needs and
cannot work around: a `chromeless` rendering mode (no native scrubber, no panel chrome, no
internal affordance button) and a readable muted-state accessor plus an `unmute()` action on
`VideoPlayer`.

Purpose: `VideoPlayer` emits the SAME `autoplay-blocked` event for a muted-retry SUCCESS and a
muted-retry FAILURE (locked decision, STATE.md). Without an exposed muted-state read, the
presentation viewer physically cannot render the UI-SPEC's two distinct affordances
("Playing muted — tap to unmute" vs "Tap to play video"). And without `chromeless`, a native
scrubber and a gray panel border render on top of the pure-black projection canvas.

Output: additive, non-breaking changes to both players plus test coverage proving the default
rendering is untouched.
</objective>
