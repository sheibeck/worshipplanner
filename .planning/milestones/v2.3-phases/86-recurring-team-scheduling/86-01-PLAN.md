  <behavior>
    - ordinalOfMonth('2026-09-06') returns 1 (day 6 -> ceil(6/7) = 1; the 1st Sunday)
    - ordinalOfMonth('2026-09-13') returns 2; ordinalOfMonth('2026-09-20') returns 3; ordinalOfMonth('2026-09-27') returns 4
    - ordinalOfMonth('2026-08-30') returns 5 (5th-Sunday month; day 30 -> ceil(30/7) = 5)
    - ordinalOfMonth('2026-09-01') returns 1 and ordinalOfMonth('2026-09-07') returns 1 (both in the first 7-day block)
    - ordinalOfMonth('2026-09-08') returns 2 (first day of the second block)
    - UTC-stability: the ordinal for a given 'YYYY-MM-DD' is identical regardless of the host/browser timezone (parsed as UTC calendar date, not local midnight) — assert an early-month date such as '2026-03-01' resolves to ordinal 1 and does not slip to the prior month
    - teamMatchesDate returns true when team.recurrence.ordinals includes ordinalOfMonth(dateStr): a team with ordinals [1,3] matches '2026-09-06' and '2026-09-20' but not '2026-09-13'
    - teamMatchesDate returns false when recurrence is absent (undefined), when recurrence.ordinals is empty [], and when the ordinal is not in the list
    - teamMatchesDate on a team with ordinals [5] matches a 5th-Sunday date ('2026-08-30') and does not match a month lacking a 5th occurrence
  </behavior>
  <action>

    every case in the behavior block, then implement to green. Create src/utils/teamRecurrence.ts
