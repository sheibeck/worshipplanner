<objective>
R248 — a one-time, owner-run backfill that corrects existing songs' `lastUsedAt` in the single
production (Berean) org, using the SAME derivation the live R247 fix uses (plan 84-01), so no
song's date disagrees between the live path and the retroactive correction.

Purpose: retroactively set every song's last-used date to the MAX date of the LOCKED services it
was ever added to — without disturbing songs that are in no service (their dates came from the
Planning Center import and must be preserved).
Output: `functions/src/backfillLastUsed.ts` (Admin-SDK Node script, dry-run by default, `--apply`
to write, single-org, idempotent) and its unit test, mirroring the backfillOrgClaims pattern.
</objective>
