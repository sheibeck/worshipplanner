<objective>
Auto-populate a service's Stage Layout ONCE from the roster's assigned roles/instruments when the
Stage Layout tab is first opened against an empty canvas (R420). This removes the "start from a blank
canvas and drag every instrument manually" step while guaranteeing that a partially-planned service's
manual placements are never touched.

Purpose: Deliver the stage-layout half of the "trivial wins" phase. All inputs already exist (Phase 107
shipped `stageServingAssignments`, `src/utils/stageLayout.ts` geometry/creation primitives, and the
`StageMarker` model) — the only new code is one pure function plus a guarded one-time trigger.
Output: `autoPopulateMarkers()` in `src/utils/stageLayout.ts`, a guarded `onAutoPopulateStageLayout()`
trigger in `ServiceEditorView.vue`, and tests for both.
</objective>
