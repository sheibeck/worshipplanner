<objective>
Add the orphan-render cleanup — dry-run by default, mirroring the post-incident shape exactly — and
close the identifier gap that would otherwise make a deck's render unfindable.

Purpose: R062's fourth criterion requires orphan cleanup for failed renders to default to
report-only. This codebase has already had a real incident from the inverse default
(`cleanupExpiredMedia`'s doc comment claimed dry-run while the code deleted on a daily 02:00 UTC
schedule; fixed 2026-07-28 in `9f1b881`). The second half closes 37-RESEARCH.md's structural finding:
the Storage `importId` and the `ImportedDeck` Firestore document id are two currently-unlinked
identifiers, so nothing today can join a deck to its render.

Output: `cleanupOrphanRendersHandler` + `cleanupOrphanRenders` in `functions/src/index.ts` with a
fail-safe regression suite, and `ImportedDeck.renderImportId` wired through `PptxImportModal.vue`.

★ **Do not invent a new gating idiom.** Mirror `functions/src/index.ts:257`'s shape exactly.
</objective>
