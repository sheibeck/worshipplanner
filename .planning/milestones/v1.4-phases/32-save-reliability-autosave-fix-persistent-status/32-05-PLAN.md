<objective>
Delete `ServiceEditorView.vue`'s hand-rolled autosave duplicate and put the view on
`useAutoSave` plus `useSaveStatus`, and replace its header status text with a sticky status bar
that stays on screen while a long Service Order scrolls.

Purpose: R040 names the de-duplication explicitly. This is the largest single change in the
phase and the one with the most preserved behaviour — the Phase 31 BL-02 lesson, the D-15
reorder path, the lock-cancel guarantee, and undo all pass through here. It runs only after
R039 is confirmed green, because migrating first would have destroyed the evidence the repro
test stands on.

Output: a view that owns `localService`, `originalService` and `isDirty` and delegates
everything else; one sticky bar; a test file whose assertions moved rather than disappeared.
</objective>
