<objective>
Define the structural contract the model is allowed to speak — a speaker enum and two integers, nothing
else — and build the client-side validator that is the sole gate between model output and scripture a
congregation will read aloud.

Purpose: `strict`/`json_schema` output guarantees *shape*, never *range* or *cross-field
relationships*. Structured outputs' JSON Schema subset has no `minimum`, `maximum`, `multipleOf`,
`minLength` or `maxLength`. Every bounds, ordering, adjacency and coverage check in R064 is therefore
explicit TypeScript, not a schema promise. This plan is where R064's claim is either established or
quietly lost.

Output: `SPLIT_SCHEMA`, the `SplitSection` type, and `validateSplitResult()` in
`src/utils/claudeApi.ts`, with an exhaustive per-failure-mode suite.
</objective>

  <action>
    Write the rejection tests first, then implement `validateSplitResult(parsed: unknown, boundaries:
    number[]): SplitSection[] | null` in `src/utils/claudeApi.ts`. Every rejection returns `null`. There
    is no partial result, no repair, no coercion and no sort — a single violation discards the entire
    result, per CONTEXT's "never partially apply a split."

    Validate in this order. Reject unless `parsed` is a non-null object carrying a `sections` key whose
    value is a non-empty array. Compute `maxIndex` as `boundaries.length - 1`. Track `prevEnd`, starting
    unset. For each element: reject unless it is a non-null object; reject unless its own enumerable key
    set is exactly the three expected names; reject unless `speaker` is one of the two legal values;
    reject unless both indices satisfy `Number.isInteger`; reject unless both fall within 0 and
    `maxIndex` inclusive; reject unless `startBoundary` is strictly less than `endBoundary`; and, when
    `prevEnd` is set, reject unless `startBoundary` strictly equals `prevEnd` — this single equality is
    what rejects a gap and an overlap identically, and what makes an out-of-order result unrepresentable
    without also being non-contiguous. Then set `prevEnd` to `endBoundary`. After the loop, reject unless
    the first section's `startBoundary` is 0 and `prevEnd` equals `maxIndex`.

    exists in code rather than in the schema: the structured-outputs JSON Schema subset supports no
    numerical constraint and no cross-field relationship, so shape conformance says nothing about range,
    ordering, adjacency or coverage.
