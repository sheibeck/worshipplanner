<objective>
Make the group's existing drop zone double as the click-to-import affordance and delete the separate
import button (R053). The drag-and-drop machinery already works and is not rebuilt — this plan adds a
click/keyboard path into the same `openImportModal()` the deleted button called, under the same gate.

Purpose: R053's stated capability, minus the button that duplicated it.
Output: `SlideDropTarget` gains a `clickable` prop and a `browse` emit; `SlideGrid` loses the import
button, wires both tile instances, and updates one line of empty-state copy.
</objective>

   spans four requirements across five source files, and because `ServiceEditorView.vue` (3,690 lines)
   is touched by R067, R068 and R069 — those three cannot run in parallel, so collapsing them into
   fewer plans would produce 5–6 task plans in the project's largest file. Same justification shape as
   Phase 37's recorded 6-plan departure.
