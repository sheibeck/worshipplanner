## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Menu dispatch → drawer mutation handlers | An action key arriving from outside the drawer reaches this component's existing write paths |
| Browser file picker → the slide's own background field | A per-slide upload crosses into Storage and then into the group document |

| T-33-15 | Elevation of Privilege | `pendingAction` watcher | critical | mitigate | The watcher re-checks the drawer's own `canMutate` gate before acting on either key, so a dispatched action cannot bypass the editor / not-locked / not-a-song-group composition even if the menu that sent it were wrong. A dedicated locked-service test asserts both keys are inert |
