<objective>
Build the authoring half of the stage layout: the freeform drag canvas and the Stage Layout tab on
the service editor. This is the app's FIRST freeform-drag surface, so it is built on native Pointer
Events with percentage coordinates and a drop-only persist path exactly as 107-CONTEXT.md / STACK /
PITFALLS prescribe (drag corruption is documented history — v1.4 phantom duplicates, v1.6
drag-into-section bugs).

Depends on 107-01 for the StageMarker type, the pure geometry helpers, and the read-only
StageLayoutView (reused for the locked state).

Purpose: Let tech/sound place instruments, mics, and monitors on-stage or off to the side, label a
one-off speaker's mic, and reposition freely — persisted per service through the existing autosave
path with zero new rules/collection/store (R313, R314).
Output: StageLayoutEditor.vue + the Stage Layout tab/panel wired into ServiceEditorView.vue.
</objective>
