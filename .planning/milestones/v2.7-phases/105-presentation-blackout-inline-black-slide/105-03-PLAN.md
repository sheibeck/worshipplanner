<objective>
Scope the runtime "Go to black" control to the Audience output only, leaving the Confidence monitor
visible — a pure consumer-side suppression in `ConfidenceOutputView.vue` with NO wire-protocol change
(CONTEXT.md / ARCHITECTURE.md Option B). This is the smaller, isolated half of the phase and is
independent of the black-slide work (105-01/105-02) — different files, different subsystem.

Purpose: fix the reported defect where "Go to black" also blanks the band's confidence monitor. Keep the
two "black" concepts cleanly separate in code and tests so a future reader does not "helpfully" re-black
the confidence monitor: the authored blackout SLIDE is content (black on both outputs, it's a slide); the
runtime "Go to black" is an operator control (now Audience-only).
Output: during a runtime "Go to black", the confidence monitor keeps rendering current/next slides.
</objective>
