Hosting docs list reserved `/__/*` ahead of configured redirects and say nothing about query strings; the emulator's redirect code appends the original query.
Hash: RFC 9110 §10.2.2 says a user agent keeps the original fragment when the Location value has none, so `#top` rides along.
