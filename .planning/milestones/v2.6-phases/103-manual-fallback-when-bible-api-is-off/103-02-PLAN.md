| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-103-02 | Tampering | "Open in BibleGateway" external anchor | medium | mitigate | The anchor uses `rel="noopener"` with `target="_blank"` so the opened BibleGateway page cannot reach `window.opener` (reverse tabnabbing) |
