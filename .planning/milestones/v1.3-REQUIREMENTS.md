## Requirements — all met

- [x] **R028** (constraint, P24): Slide groups are owned by service plan items — group order and membership mirror the service plan, so reordering an element on Service Order reorders its slides with no second manual reorder. Slide content, media and audio are independent of the plan.
- [x] **R029** (failure-visibility, P24): Deleting a service plan item deletes its slide group, but only behind an explicit warning naming what will be lost and a confirmation — never a silent cascade. (Superseded the original orphaned/unanchored design per user decision 2026-07-25; orphan reassignment is deferred.)
- [x] **R030** (core-capability, P24): Audio attaches at two levels — a group-level bed that plays across the group, and per-slide audio with a scope toggle and a loop-until-next-slide flag. Replaces Phase 22's slot-level media (D008).
- [x] **R031** (primary-user-loop, P25): A Slides tab where all slide editing lives — a plan rail mirroring service order (not draggable) plus a slide grid for the selected group.
- [x] **R032** (core-capability, P25): A slide deck, image, video or audio file can be added at any point in the service, not only in Announcements/Sermon — imports and media append to the selected group.
- [x] **R033** (core-capability, P26): An Edit Slide drawer that floats over the page without reflowing it, carrying slide preview, label, read-only text with an "Edit in song" link (D007), slide audio with scope and loop, operator-only notes, and delete.
- [x] **R034** (quality-attribute, P27): The first tab is named "Service Order" and carries no slide editing.
- [x] **R035** (quality-attribute, P28): The song lyrics editor presents one scroll surface and one list that IS the slide order — no nested scrollbar, no duplicated Available-Sections / Performance-Order lists.
