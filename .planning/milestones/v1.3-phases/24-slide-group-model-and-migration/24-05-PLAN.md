<objective>
Wire the reactive layer: subscribe the `slideGroups` store on org change, lazily materialize a group
for every plan slot that lacks one (carrying its Phase 22 media onto the bed), and trigger
reconciliation when a source has changed shape — all without introducing a second save path and
without a single write on reorder.

Purpose: this is where D-05's lazy migration actually happens and where D-01's "a reorder can never
touch a group" guarantee is proven.
Output: `useSlideshowAssembly` extended in place, with its test file extended alongside.
</objective>

Add a materialization watcher to the composable, mirroring `loadMissingLyrics`'s shape: watch the
service's slots plus the resolved org id plus `groupsBySlotId`, and for each slot with no group,
build the input with `buildInitialGroup(slot, service.id, inputs)` and call
`slideGroupsStore.materializeGroupIfMissing(orgId, input)`. Gate the whole body on `canWrite`.

Skip a slot whose `buildInitialGroup` produces an empty `slides` array. A SONG slot with no song
assigned has nothing to populate, and D-02's "groups are always populated" is satisfied by not
creating a document at all rather than by creating an empty one. The slot's deprecated media stays on
the slot in that window and is picked up by `buildInitialGroup` at the moment the source resolves, so
nothing is lost. Record this as an explicit planner decision in the summary.

Guard against re-entrancy: keep a local `Set<string>` of slot ids with a materialization already
in flight, so the watcher firing again before the `onSnapshot` round-trip lands cannot issue a second
write for the same slot. This is belt-and-braces on top of the deterministic doc id, not a substitute
for it.

The watcher must key ONLY on `slot.id`. Never index into a group list by array position, never read
`slot.position` to find a group, and never write anything in response to a position change. This is
the entire point of D-01: `reindexSlots` rewrites every `position` on every drag, and a group must not
notice.

Do not clear or rewrite `slot.audioUrl` / `slot.videoUrl` anywhere. They are deprecated-but-readable
(D-05) so a partially migrated organization keeps a working fallback.

Extend the composable test file with all the behaviors above. The reorder case is the important one:
mount, let materialization settle, reset the store action mocks, reorder the slots, flush, and assert
every `slideGroups` write mock has a zero call count.
