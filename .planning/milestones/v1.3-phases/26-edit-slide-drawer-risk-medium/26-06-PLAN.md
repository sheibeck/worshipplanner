## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-06-01 | Tampering (destructive) | taking the source's version | high | mitigate | Gated behind an explicit confirmation naming concrete counts and kinds, never automatic, never reachable by an accidental click beside the dialog, and never by Escape (which declines). |
| T-26-06-02 | Elevation of Privilege | opening affordance shown to a viewer | medium | mitigate | The affordance is gated on the write-capability prop, matching the component's existing write controls, with server-side org-editor rules behind it. |
| T-26-06-03 | Tampering (data loss) | replace with a stale base snapshot | high | mitigate | The apply write passes the group's current slides as its base snapshot, so a concurrently-added entry is merged rather than erased — the same discipline every other write path in this feature follows. |
