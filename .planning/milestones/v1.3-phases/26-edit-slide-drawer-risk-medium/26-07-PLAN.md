<objective>
Give the panel its Slide Text section: read-only for words that live somewhere else, editable for words
that live here, with the right route away per source and a confirmation before leaving unsaved work
behind.

Purpose: this is where D-13's read-only rule, D-15's per-source matrix and D-14's navigate-by-route rule
all land at once, and where the two navigation targets built in 26-02 and 26-03 finally get used. The
matrix is the single most load-bearing table in the UI spec because getting the branch key wrong — the
resolved content kind instead of the stored source kind — silently gives an imported picture a
lyrics-editing route.
Output: a per-source words section, an inline editor for hand-written slides, two routes away, and an
unsaved-work confirmation on both.
</objective>
