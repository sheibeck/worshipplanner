<objective>
Give the panel its Slide Audio section: a scope choice between this slide and the whole group, a loop
flag that exists only where it means something, the three states the section can be in, and an honest
degraded state for a file that is no longer there.

Purpose: this is the half of R033 that touches the group's shared music, so getting the routing wrong
would either duplicate a URL across every slide or quietly break the precedence model Phase 24 and the
Phase 25 review already settled. It also carries D-12's hard omission for video slides, which exists
because a video already suppresses the group's music for its own duration — offering a second audio
attachment there would recreate exactly the conflict the model was built to prevent.
Output: the audio section in all three states, both write routes, and the unavailable state.
</objective>
