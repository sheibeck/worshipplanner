<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| drag library callbacks → editable state | A third-party library supplies the indices that drive a reorder of persisted data. |
| row action click → Firestore lyrics document | Remove is a destructive action reaching persisted lyric text with no confirmation step. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-16 | Tampering | drag end handler indices | medium | mitigate | The handler returns early on absent or equal indices, and `moveRow` treats an out-of-range index as a no-op returning an equal array — an out-of-range callback cannot corrupt the order. |
| T-28-17 | Tampering | last-occurrence removal destroys lyric text | high | mitigate | Destruction is confined to `removeRow`'s tested branch and reaches only the section losing its final reference; version history remains available from the editor header to recover an earlier document. |
| T-28-18 | Denial of Service | repeated duplicate actions | low | mitigate | Each duplicate appends exactly one order entry and no pooled section, so growth is linear in user clicks and adds no text; 28-03 proved reconciliation is stable under repeats. |
| T-28-19 | Tampering | drag library DOM mutation | medium | mitigate | The library's DOM move is reverted inside the handler so Vue's render remains the single source of truth, the established codebase remedy for the snap-back defect. |
| T-28-SC | Tampering | package installs | high | accept | This plan installs nothing. The drag library is an existing project dependency already used by two other surfaces. |
</threat_model>
