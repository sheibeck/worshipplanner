<objective>
Extract the ~90%-shared output-window lifecycle-core out of AudienceOutputView.vue into a new
`src/composables/useOutputWindow.ts` and refactor AudienceOutputView to consume it — WITHOUT changing
any observable audience behavior and WITHOUT touching AudienceOutputView.test.ts. This is the
"reuse, don't fork" foundation Phase 94's confidence view (94-02) builds on: both output windows will
share this one lifecycle-core and supply only their own render body + per-canvas media plumbing.

Purpose: R272 is delivered by a SIBLING of the Phase 93 audience window. Per the milestone's
reuse-not-fork principle and the 94-PATTERNS extraction assessment (CLEAN, low-risk), the shared
service-load + WR-02 subscribe gate + read-only assembly + receive-only channel + font gate + cursor
coupling + fullscreen-loss recovery + Screen Wake Lock become a single composable instead of being
copy-pasted into a second view. The two hard conditions from the assessment are load-bearing and are
encoded here: (1) channelFactory is threaded through as a composable argument (or the Phase 93 channel
tests break); (2) the per-canvas media watcher stays in each view (audience = 1 live canvas;
confidence = 1 live canvas + 1 non-autoplaying preview).

Output: `src/composables/useOutputWindow.ts` and a refactored `src/views/AudienceOutputView.vue`.
The confidence view and route land in 94-02; all new test authoring (confidence view test + a direct
useOutputWindow unit test) lands in 94-03. The regression gate for THIS plan is the existing,
unmodified 18-test audience suite.
</objective>
