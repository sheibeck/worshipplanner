    Create src/composables/useRunTimers.ts exporting `export function useRunTimers()`:
    - `const clock = ref('')` and `const elapsedMs = ref(0)`; a non-reactive `let startedAt: number | null = null`
      and `let id: ReturnType<typeof setInterval> | null = null`.
    - `const elapsed = computed(() => formatElapsed(elapsedMs.value))`.
    - `function startElapsed() { if (startedAt == null) startedAt = Date.now() }` — idempotent: only the FIRST
      call (first go-live OR rehearse) sets the origin; later calls are no-ops.
    - `function resetElapsed() { startedAt = null; elapsedMs.value = 0 }`.
    - `function tick() { clock.value = formatClock(new Date()); if (startedAt != null) elapsedMs.value = Date.now()
      - startedAt }`.
    - `formatClock(d: Date): string` → a short wall time (e.g. `d.toLocaleTimeString([], { hour: 'numeric',
      minute: '2-digit' })`).
    - `formatElapsed(ms: number): string` → total seconds = Math.floor(ms/1000); mm = String(Math.floor(s/60 %
      60)).padStart(2,'0'); ss = String(s % 60).padStart(2,'0'); hh = Math.floor(s/3600); return hh > 0 ?
      `${hh}:${mm}:${ss}` : `${mm}:${ss}`. No Array.prototype.at anywhere.
    - onMounted: `tick()` once, then `id = setInterval(tick, 1000)`. onUnmounted: `if (id != null) { clearInterval(
      id); id = null }`.
    - RETURN `{ clock, elapsed, startElapsed, resetElapsed }`.

    Create src/components/run/__tests__/useRunTimers.test.ts: define a tiny harness component that calls
    useRunTimers and exposes clock/elapsed/startElapsed/resetElapsed; use vi.useFakeTimers()/vi.setSystemTime in
    beforeEach + vi.useRealTimers() in afterEach. Cases: (1) clock is non-empty after mount and updates after
    advanceTimersByTime(1000) with a changed system time; (2) elapsed is '00:00' before startElapsed, and after
    startElapsed() + advanceTimersByTime(65000) reads '01:05'; (3) resetElapsed() returns elapsed to '00:00';
    (4) startElapsed() twice keeps the FIRST origin (idempotent). Never rely on real time.
