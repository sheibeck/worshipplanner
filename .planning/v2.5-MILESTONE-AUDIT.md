# Milestone v2.5 — Invite Email & Non-Google Onboarding · Audit

## Origin

This milestone came out of vetting the non-Gmail login path (`/gsd-debug` →
`.planning/debug/resolved/non-gmail-password-setup.md`): the in-app TeamView invite only wrote Firestore
docs — it never sent an email or provisioned a Firebase Auth account, so non-Google invitees had no
discoverable way to get a password and "reset password" could not help.

id/normalization (`organizations/{orgId}/invites/{trim().toLowerCase()}`) vs. the function's CR-01
invite-existence gate — is byte-identical on both sides. `sendInviteOnboardingEmail` is re-exported from
`functions/src/index.ts` (deploy-safe). The `appConfig.onboarding.emailsEnabled` toggle written by
`OnboardingConfigCard` is the same field the server reads. `ensureUserDocument`'s invite-acceptance path is
untouched.
