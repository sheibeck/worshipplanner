## 2. Milestone-Goal Achievement — Full Path Traced

Goal: *"Bible API access behind a per-org on/off switch controlled from the Owner Console, and when off a zero-cost manual path (BibleGateway deep-link + paste-in) so scripture/congregational features always work."*

Traced end-to-end against the real committed code (not narrative):

1. **Super-admin toggles per-org** — `OrgConfigDrawer.vue:78-96` checkbox → `OrganizationsTab.vue:708-729` `onToggleBible` → `httpsCallable(functions, 'setOrgBibleEnabled')({orgId, enabled})`.
2. **Org field, default OFF** — `setOrgBibleEnabledHandler` (`functions/src/orgProvisioning.ts:770-820`) merge-writes `bibleApiEnabled` + audit siblings via Admin SDK; no onboarding path writes the field (confirmed by grep — only `setOrgBibleEnabledHandler` touches it); every read defaults `?? false`.
3. **Client dispatcher gate** — `scriptureApi.ts::fetchScriptureText` reads `useAuthStore().isBibleApiEnabled` FIRST and returns `{status:'disabled'}` before any fetch. `isBibleApiEnabled` (`auth.ts:182`) mirrors the org field via `applyOrgSnapshot` (`auth.ts:461`).
4. **Server esv/nlt gate** — `checkOrgBibleEnablement` (`functions/src/index.ts:403-428`), wired into the `api` proxy's `esv`/`nlt` branches (`:740-751`) strictly before the shared upstream `fetch()` (`:754`); resolves org from the verified ID-token claim (`resolveOrgId(decodedCaller!)`), never a client-supplied value; fails closed (503) on a Firestore read error.
5. **Disabled org gets BibleGateway deep-link + paste-in** — both `ScriptureInput.vue` and `CongregationalEditor.vue` render a fallback block (`v-if="!authStore.isBibleApiEnabled"`) with a `bibleGatewayLink()` anchor and a paste textarea wired into the same reactive state the enabled/fetch path uses (`previewText` / `rawPassage`+`text`), confirmed by dedicated tests exercising paste→Save and paste→Split.
6. **Settings hides the translation selector** — `SettingsView.vue:319` `v-if="authStore.isBibleApiEnabled"`.

Every link in this chain was independently confirmed by direct source read (not summary trust). Two genuine data-loss bugs were caught in Phase 103's own code-review cycle before this milestone was ever presented for verification (CR-01: pasted text silently erased by a reference edit or the still-visible Preview button; CR-02: paste-box keystrokes clobbering an AI split or manual edit) — both are fixed, with dedicated regression tests, independently re-run and passing (see §6). This is exactly the kind of state-transition/no-clobber invariant that a shallower audit would have missed; it was caught and closed before merge.
