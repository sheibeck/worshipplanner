Build the two focused slide-over editors that the read-only Roles/Teams panels (Plan 03) will open:
**RoleSlideOver** (edit/create/delete a role's name, group, default count, and Band-only vocal flag)

`SongSlideOver.vue`'s drawer shell. TeamSlideOver **absorbs** the Phase-86 `TeamRecurrenceSlideOver`
so there is ONE team drawer, not two (R257).

a read-only row. These components are that slideout; Plan 03 wires them into RosterView and removes the
old inline editors + the recurrence-only drawer.
Output: `RoleSlideOver.vue`, `TeamSlideOver.vue`, and their tests. No consumer is wired yet (Plan 03).
</objective>

    - Open with role=null (create): filling name + clicking Save calls rosterStore.addRole with { name (trimmed), group, defaultCount, order: maxExistingOrder+1, and vocal:true ONLY when group==='band' and the box is checked }, then emits 'saved'.
    - Open with an existing role (edit): the fields prefill from the role; changing them + Save calls rosterStore.updateRole(role.id, { name (trimmed), group, defaultCount, vocal: group==='band' ? checked : false }), then emits 'saved'.
    - The vocal checkbox is present only while group==='band'; switching group away from Band hides it and forces vocal:false on save.
    - Delete (edit mode only): first click reveals the confirm copy naming the role and stating existing assignments across all quarters will be cleared; confirming calls rosterStore.deleteRole(role.id) and emits 'deleted'.
    - open=false renders nothing (v-if on the panel), matching SongSlideOver.
  </behavior>
  <action>
    Create `src/components/RoleSlideOver.vue` modeled on `SongSlideOver.vue`'s shell. Props:
    `open: boolean`, `role: Role | null` (import `Role`, `RoleGroup` from `@/types/roster`). Emits:
    `close`, `saved`, `deleted`. Use `useRosterStore()`.

    Copy SongSlideOver's Teleport + backdrop Transition + right-drawer Transition (`translate-x-full`,
    `max-w-[480px]`, `bg-gray-900`) + header (title `New Role` when role===null else `Edit Role`, a Cancel
    button, a Save button, and the close ×). Seed a local form from `props.role` on `open` becoming true
    (watch `() => props.open`), or an empty form (group default 'band', defaultCount 1, vocal false) when
    role===null. `isCreateMode = computed(() => props.role === null)`.

    For edit: call `updateRole(role.id, { name, group, defaultCount, vocal: group === 'band' ? vocal : false })`.
