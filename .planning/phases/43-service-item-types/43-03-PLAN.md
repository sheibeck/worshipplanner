<objective>
Give the planner the editor surface: two new palette chips, one shared free-text editor serving
Message, Announcements and Miscellaneous, the Message URL control removed, and the Hymn chip retired
from both palette rows.

is gone — is plan 04's job, and this plan must not claim it.

a plain text box; Hymn is no longer offered.
Output: the finalized add-item palette Phase 44's template editor consumes, and one editor control
shared by three kinds rather than three near-identical copies.
</objective>
