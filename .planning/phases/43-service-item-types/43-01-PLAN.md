<objective>
Widen `SlotKind` with `ANNOUNCEMENTS` and `MISC`, add the one shared optional `body` field to
`NonAssignableSlot`, and close every kind-dispatch site the compiler surfaces plus the two it cannot.

This plan runs FIRST and alone in wave 1 on purpose. `npm run type-check` (the `vue-tsc --build` form)
is this phase's primary defect detector: widening the union makes the compiler enumerate every
exhaustive `switch (slot.kind)` in the codebase that needs a new case. Sequencing the widening early
means the compiler drives plans 02-04 rather than being run at the end as a formality.

Purpose: establish the finalized type contract Phase 44's template editor depends on, and make the
work list for the rest of this phase machine-generated rather than guessed.
Output: a type-clean codebase in which ANNOUNCEMENTS and MISC are constructible, labelable,
badge-able, materializable and presentable — with no editor UI and no Planning Center branch yet.
</objective>
