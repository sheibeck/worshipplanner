<objective>
Deliver R259: generalize the Phase-85 vocals-only "sing & play" exemption into a per-role
**multiRole** flag settable on ANY role in ANY group, and rewrite the co-occurrence rule so a
multi-role role never conflicts (crossing Band/Tech/Other) while non-multi roles keep one-role-per-date
exclusivity and the ≤1 non-multi Band-instrument cap.

This is an atomic rename ripple (`Role.vocal` → `Role.multiRole`) across the type, the scheduler rule,
the store projection, the read-time compat shim, three components, and all coupled test fixtures — plus
a genuine behavior change to `evaluateGroupCombo` (filter multi-role roles OUT first, then apply the
existing rule to the remainder). Every consumer moves in ONE plan because `npm run type-check`
(vue-tsc --build) typechecks the test files too, so the rename is only type-clean when it lands whole.

Purpose: replace the vocals special-case with a general concept so a worship leader (who sings + plays
bass + leads) can be flagged multi-role and co-occur across groups; this flag is also the substrate the
Wave-2 bundling weight (Plan 02, R260) reads.
Output: `Role.multiRole` type + rewritten `evaluateGroupCombo` + compat shim + generalized RoleSlideOver
control with helper text + updated badges/warn + all green tests.
</objective>
