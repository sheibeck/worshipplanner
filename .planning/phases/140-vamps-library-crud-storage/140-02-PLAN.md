## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Cloud Storage `orgs/{orgId}/vamp-files/{vampId}/{uploadId}/…` | Any authenticated caller can attempt an upload/read/delete against a guessed or crafted path — storage.rules is the sole authority |
| client → Firestore `organizations/{orgId}/vamps/{id}` | Any authenticated caller can attempt vamp doc CRUD — the generic firestore.rules catch-all is the sole authority |
| catch-all block ↔ dedicated vamp-files block | Cloud Storage OR-combines sibling match blocks; a permissive catch-all can override a stricter dedicated block unless the path is excluded |
