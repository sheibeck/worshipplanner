    - pctWithinRect(clientX, clientY, rect) returns { xPct, yPct } as the point's percentage offset within the rect, each clamped to [0,100] — a point at the rect's left/top edge is 0, at right/bottom edge is 100, and a point outside the rect clamps rather than exceeding the range.
    - Round-trip stability: for a rect of width W/height H, converting a pct to a pixel offset and back through pctWithinRect returns the original pct (within floating tolerance) — the property that makes positions reload-exact and resize-stable (R314).
    - zoneFromPoint(clientX, clientY, { onstage: rectA, offstage: rectB }, fallbackZone) returns 'onstage' when the point is inside rectA, 'offstage' when inside rectB, and returns fallbackZone when the point is inside neither (drop outside any zone keeps the marker's current zone).
