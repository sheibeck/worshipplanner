<objective>
Wire the client-side super-admin gate and the minimal Owner Console (R177, R179 UI):
- surface `isSuperAdmin` in the Pinia auth store from the existing token-claims read,
- add the `requiresSuperAdmin` route meta, the `/owner-console` route, its guard branch, and the gated "Owner Console" nav entry,
- build `OwnerConsoleView.vue` — a minimal, extensible shell hosting a super-admin roster panel (list / grant-by-email / revoke).

The client gate is CONVENIENCE only — the real enforcement is the Firestore rules (Plan 03) plus the onCall caller re-check (Plan 02). The route guard must therefore never be treated as access control; the roster's privileged writes go exclusively through the `setSuperAdminClaim` callable (server-side re-verified), never a direct client write to `superAdmins/*` (which the rules gate to super-admins only anyway).

The route path is deliberately `/owner-console` (title "Owner Console"), NOT `/admins` — the per-org TeamView already owns `/admins`. UI is intentionally minimal: the shell keeps a section/slot layout Phase 70 will fill with config-editor panels; do NOT build config editing here.

Purpose: A signed-in super-admin can reach the console and grant/revoke another user; everyone else is kept out client-side (R177, R179).
Output: modified `auth.ts` / `router/index.ts` / `AppSidebar.vue` and new `OwnerConsoleView.vue`.

Note: this plan has no compile dependency on Plans 02/03 (it references the callable by name only), so it runs in Wave 1. Everything ships UNDEPLOYED per the v1.9 hand-over discipline.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser route guard → app views | The guard hides/redirects the route; it is UX only and enforces nothing server-side. |
| OwnerConsoleView → setSuperAdminClaim (onCall) | Privileged grant/revoke crosses to the server, which independently re-verifies the caller (Plan 02). |
| OwnerConsoleView onSnapshot → Firestore (superAdmins/*) | The live roster read is gated by the isSuperAdmin() rule (Plan 03), not by the route guard. |
