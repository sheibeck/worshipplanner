Contracts this plan CREATES in src/originHandoff/bridge.ts (imports only ./allowlist and ./codec):
- `export const NEW_ORIGIN = 'https://worshipbuilder.web.app'`
- `export function normalizePath(pathname: string): string` returns a single '/' followed by the pathname with all leading slashes removed ('' becomes '/', '//evil.com/x' becomes '/evil.com/x').
- `export function collectHandoffEntries(storage: Storage): Array<[string, string]>`. It walks `storage.length` / `storage.key(i)` (each read in try/catch) and keeps keys where matchRule is non-null and the raw value is a non-null string of at most MAX_VALUE_CHARS whose `rule.validate(raw)` returns a value. It returns canonical [key, value] pairs sorted by rule index in HANDOFF_RULES, then by key, and capped at MAX_ENTRIES. It never throws (returns [] on error).
- `export interface BridgeDeps { location: Pick<Location, 'pathname' | 'search' | 'hash'>; storage: Storage | null }`
- `export function planBridgeRedirect(deps: BridgeDeps): string`. It never throws; the outer catch returns NEW_ORIGIN + '/'. With base = NEW_ORIGIN + normalizePath(pathname) + search and hash = location.hash, it returns base + hash (no payload, flag untouched) when any of these holds:
  - storage is null, or reading HANDOFF_DONE_KEY throws or finds a non-null value;
  - hash is non-empty and fails isRestorableHash;
  - there are no entries;
  - not even one entry fits in the size budget.
  Otherwise:
  - add entries in order while encodeFragment({ v: 1, k, h: hash or omitted }) stays at most MAX_FRAGMENT_CHARS;
  - set HANDOFF_DONE_KEY to '1' (try/catch);
  - return base + that fragment.
