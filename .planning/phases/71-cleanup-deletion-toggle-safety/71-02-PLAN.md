<objective>
Add the confirm-to-flip client flow (R189) and enforce the song-linked-background hard block (R190) in
the Owner Console. Replace Phase 70's read-only cleanup toggles with an Enable→preview→confirm flow: to
enable, fetch the dry-run count from `previewCleanupDryRun`, show a confirm dialog echoing it, and only
on explicit Confirm write `cleanup.{x}Enabled=true`. Disable is immediate, no preview. When the
backgrounds preview returns `referencesComplete:false`, the dialog's Confirm is hard-disabled with no
override.

Purpose: No cleanup flag is ever flipped on blind — the owner sees exactly what would be deleted right
now, and a song-linked background can never be armed for deletion while references are unproven.

Output: New `CleanupEnableConfirmDialog.vue`, extended `CleanupConfigCard.vue`, and their tests. Client
ships built + tested (the actual production enable remains the owner's button). The callable is invoked
by string name (`previewCleanupDryRun`), so this plan does not build-depend on 71-01 — it is sequenced
after it for coherence.
</objective>
