<objective>
Add the cleanup backstop for R423: a `cleanupStalePresence` scheduled cron sibling in
`functions/src/cleanupSweeps.ts` that removes abandoned presence docs (a crashed/closed
tab leaves one, since Firestore has no onDisconnect), gated dry-run-by-default via a new
`cleanup.presenceEnabled` app-config flag, re-exported from `functions/src/index.ts`, and
unit-tested. The client soft-TTL (Plan 02) is the real-time signal; this cron is the
eventual sweep so presence docs never accumulate forever.

Purpose: Without a backstop, every ungraceful disconnect leaves a permanent presence doc.
This mirrors the existing retention crons' fail-safe discipline (dry-run until the owner
explicitly enables, delete cap, partial-failure tolerance).
Output: the handler + onSchedule wrapper, the app-config gate, the index.ts re-exports,
and the functions test.
</objective>
