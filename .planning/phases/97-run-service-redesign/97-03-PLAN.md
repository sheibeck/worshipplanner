<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| control -> output blackout (BroadcastChannel) | The output only READS state.blackout and renders an overlay; it never postState — the control stays the single writer, and the overlay is a pure client render of an already-typed protocol field |
| getScreenDetails / requestFullscreen (output context) | Self-fullscreen resolves its own screen from a granted permission + localStorage mapping; every call is feature-detected + try/catch-swallowed so a missing permission, absent API, or unresolvable screen degrades to the manual affordance instead of throwing at a congregation |
| localStorage monitor mapping -> screen resolution | loadMapping/computeFingerprint read untrusted localStorage and are pure/never-throw (Phase 91); a mismatch yields a plain requestFullscreen() fallback, never a crash |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-97-03-01 | Denial of Service | requestFullscreen/getScreenDetails throwing on mount | high | mitigate | Feature-detect getScreenDetails; every requestFullscreen + getScreenDetails call is try/catch-swallowed; no screen resolvable falls back to a single plain requestFullscreen() then the manual affordance — the projector never crashes or flashes an error. |
| T-97-03-02 | Repudiation | claiming fullscreen success it cannot prove | medium | accept | Cross-monitor fullscreen is only provable on hardware; the unit tests assert requestFullscreen is CALLED (mock), and the manual re-enter affordance remains as the honest fallback (human-UAT confirms the real behaviour). |
| T-97-03-03 | Information Disclosure | blackout leaking the slide underneath | medium | mitigate | The overlay is a full-bleed absolute inset-0 bg-black painted ABOVE the SlideCanvas; blackout:false removes it (return to slide) — no partial reveal. |
| T-97-03-04 | Tampering | last-slide reflow / background reveal regression on confidence | medium | mitigate | The next wrapper stays unconditionally present (fixed basis) and both panes keep suppressBackground=true; the existing ConfidenceOutputView suite (suppression + no-reflow) is the green gate, with new left/right coverage in 97-07. |
| T-97-03-SC | Tampering | package installs (npm) | n/a | accept | No installs — existing composable + views only. |
