<objective>
Rename the app on every web-app screen to WorshipBuilder (R446). That covers the 14 UI literals U1-U14 in 144-UI-SPEC: the tab title, the app splash, the sidebar and mobile header, the login and church-picker screens, the three volunteer pages, and the "Shared from" / "Generated from" footers on share, quarter-share, service-print and roster-print. Every component brand site gets a mounted rendered-text assertion (CONTEXT: "tests must assert the rendered text"). That includes two new minimal test files for VolunteerSignInView (U7) and RosterPrintLayout (U14).

Purpose: "Worship Planner" is taken. The owner locked "WorshipBuilder" (backlog 999.2). This plan does the visible half of the rename. Plan 144-02 does the email half and adds the static regression guard. The guard's source assertion is the coverage for index.html (U1) and the App.vue splash (U2). Those two are an explicit exception recorded in ADR-0246: index.html is not a component, and mounting the App root for one string adds a heavy harness (orchestrator decision 2026-10-27, under the owner's "take all your recommendations").

File-count note: every source edit in this plan is a single-token change on one line (ShareView has two such lines). The 13 source files are therefore one mechanical inventory pass, not 13 units of work, and no further split is needed.

CONTEXT decisions implemented (CONTEXT.md bullets are unnumbered; named here for traceability):
- "Brand form: WorshipBuilder, one word, capital W and B, in every surface" (index.html, App.vue, AppSidebar, AppShell, LoginView, SelectChurchView, the three volunteer views, the ShareView x2 and QuarterShareView "Shared from" footers, the ServicePrintLayout and RosterPrintLayout "Generated from" footers): Tasks 1 and 2.
- "What is NOT renamed" (claudeApi.ts role phrase; code comments and symbols; Firebase project id, wp storage keys, package and repo names; favicon): enforced by the prohibitions and diff gates in both tasks.
- Claude's Discretion "constant vs literal": edit each literal in place, with no shared constant. index.html cannot consume one, and a constant would add an import and binding to 13 files for no behavioral gain (RESEARCH / UI-SPEC recommendation). Tests assert the rendered text.
- "Shipping: no deploy in this phase": this plan runs no deploy.

Output: 13 single-token UI edits; 9 existing test files that each gain an R446 rendered-text assertion; 2 new minimal mounted test files (VolunteerSignInView, RosterPrintLayout).
