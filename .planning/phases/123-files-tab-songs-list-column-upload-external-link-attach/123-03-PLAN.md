## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| editor browser -> Firestore song doc | Link-attach and upload persist attachment metadata (incl. external href) via `updateSong` onto the org-scoped Song document. |
| stored link href -> new browser tab | A link row opens the stored href in a new tab. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-123-03 | Tampering (tabnabbing) | link-open anchor in the list | low | mitigate | Link rows open with `target="_blank" rel="noopener noreferrer"`; the href was https-validated at attach time (plan 123-01 `isValidExternalLink`). |
| T-123-04 | Information disclosure | Files tab count badge + list | low | accept | Per UI-SPEC Access Control, visibility of *that there are files* is intentionally unrestricted; `/songs` is `requiresEditor` so only editors reach this panel, and every mutation flows through the editor-gated `updateSong` / Phase 122 `storage.rules`. |

No package-manager installs occur in this phase; the package-legitimacy gate is not applicable.
