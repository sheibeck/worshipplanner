# Plan 18-06: Performance Order Builder with Drag-and-Drop

Create the performance order builder where users arrange section order with repeats using drag-and-drop.

1. Create src/components/PerformanceOrderBuilder.vue:
   - Props: sections (LyricSection[]) — available sections from parsed lyrics, performanceOrder (string[]) — current order
   - Emits: update:performanceOrder (string[])
   - Layout:
     a. Left panel: "Available Sections" — list of all parsed section labels as clickable chips/buttons. Click adds that section to the end of the performance order. Sections can be added multiple times (for repeats like Chorus appearing 3x)
     b. Right panel: "Performance Order" — ordered list of section references. Each item shows: section label, drag handle, remove button (x)
     c. SortableJS integration for drag-and-drop reorder on the right panel
   - SortableJS pattern: follow ServiceEditorView exactly — revert SortableJS DOM move in onEnd, then update the reactive array so Vue re-renders as single source of truth (prevents snap-back bug)
   - On any change (add, remove, reorder): emit update:performanceOrder with the new array of section IDs
   - Show a "Reset to Default" button that restores the default order (each section once in definition order)
   - Dark-first styling: drag handle icon in gray-500, section chips with indigo accent, ordered list items in gray-800 cards

2. Create src/components/__tests__/PerformanceOrderBuilder.test.ts:
   - Test clicking a section adds it to the order
   - Test clicking a section multiple times adds repeats
   - Test removing a section from the order
   - Test reset to default restores definition order
   - Test emits update:performanceOrder on changes
