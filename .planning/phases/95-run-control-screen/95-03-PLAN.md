## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| control view -> BroadcastChannel (single writer) | The control is the ONLY writer of `state`; a view-owned monotonic seq must never regress or the outputs' stale-drop would reject legitimate advances (or accept a stale resend) |
| ?org= query + :serviceId param -> Firestore subscription | Org/service are URL-influenceable; reads gated by existing Firestore org-membership rules (inherited via useServiceAssembly's WR-02 gate) |
| keyboard/input focus -> navigation | A stray Escape must never tear down a live service; nav keys must not fire while a dialog or a text input is focused |
| router/nav -> control access | Any authenticated org member may open /run (intended per R275); presentation-only, no editor tier |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-95-06 | Tampering | seq monotonicity / postState | high | mitigate | seq is a single view-owned counter incremented ONLY inside postIndex/resendCurrent (never reset); every navigation and every onHello resend advances it, so runChannel's onState stale-drop (seq must strictly exceed the highest delivered) accepts each legitimate update and a reopened output can never be driven backward. Asserted in 95-05. |
| T-95-07 | Denial of Service | stray Escape / double Escape teardown | high | mitigate | Escape only OPENS the confirm dialog; handleKeydown returns early while confirmOpen, so a second Escape while the dialog is open is inert (leaves Cancel focused). Teardown (close outputs + channel.close + navigate) happens ONLY on the red confirm click — a stray/double Escape can never end a live service. |
| T-95-08 | Tampering | out-of-range / null index render | low | mitigate | current/next use assembledSlideshow[i] / [i+1] ?? null (direct index access, no wrap); a null or out-of-range index renders no SlideCanvas (loading) or "End of service", never a crash or a jump to slide 0. |
| T-95-09 | Elevation of Privilege | /run route access tier | low | mitigate | The route is requiresAuth-only with no requiresEditor; the control screen exposes zero edit affordances and only broadcasts presentation state — a viewer running a service gains no write path (R275). |
| T-95-SC | Tampering | package installs (npm) | n/a | accept | No package-manager installs — in-repo composables/utils/components only; supply-chain checkpoint not applicable. |
