<objective>
Add the Run entry point (R261/R275): a prominent, welcoming Run button on the LOCKED read-only view of
ServiceEditorView that opens the standalone Run/control screen via ordinary SPA navigation. This is the
one place a locked service is normally viewed, and the button must be reachable by ANY authenticated org
member — editor OR viewer — because running is presentation-only and grants no edit ability.

Purpose: R261 (a Run button appears on a locked service and opens a dedicated standalone screen; absent/
disabled on a draft) and R275 (any authenticated member, editor or viewer, may Run; no new RBAC tier).
The button is a deliberate divergence from every other action in this view, which gate on canEditService
(editor-only, and inverted on lock) — Run gates on membership/org instead.

Output: a modified src/views/ServiceEditorView.vue. The /run/:serviceId route the button navigates to is
registered in 95-03; the button test is authored in 95-06. Because onRun pushes a plain string URL, this
plan type-checks independently of the route's existence.
</objective>
