Build the two Rehearse leaf components that browse a service's songs: `RehearseSongList.vue` (Column 1 / mobile Screen A — the selectable song list with key + PDF/MP3 counts + now-playing indicator, R385) and `RehearseSongDetail.vue` (Column 2 / mobile Screen B — Sheet music & chords with Print+Download, Recordings with Play+Download, and external links, R386/R390).
