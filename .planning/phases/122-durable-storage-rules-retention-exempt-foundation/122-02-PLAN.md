## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scheduled cleanup sweeps (Admin SDK) → Cloud Storage | Sweeps run with Admin privileges (bypass storage.rules); the ONLY thing keeping them off song-files/ is their anchored path-guard regexes — a structural, not runtime, boundary. |
| editor session (client) → Cloud Storage delete | hardDeleteSong issues a client-initiated deleteObject on permanent song deletion; the boundary is the isOrgEditor rules grant (Plan 122-01). |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
