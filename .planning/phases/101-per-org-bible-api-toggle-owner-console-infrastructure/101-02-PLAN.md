| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-101-06 | Tampering | authStore bibleApiEnabled mirror | low | accept | the client mirror is UI-gating only, never the security boundary — the real gate is firestore.rules + the callable (Plan 01). Defaults false when absent, so a tampered/missing snapshot fails safe (OFF) |
