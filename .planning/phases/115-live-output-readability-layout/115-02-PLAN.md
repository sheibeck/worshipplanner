<objective>
Make the live Run/control screen readable at a glance: shrink the dominant On-screen preview so it no longer crowds the thumbnails (R330), enlarge the in-item filmstrip thumbnails while preserving the reference-stage scaling that stops text re-wrapping (R330), add an end-of-item cap that names the next service item so the operator sees an item is ending and what is next (R331), and force the filmstrip's horizontal scrollbar to stay visible on macOS with an edge fade signalling off-screen content (R332).

Purpose: These are the operator-facing readability fixes surfaced by the first real church-projector run. They are independent of the auto-fit engine work (Plans 01/03) — different files — so this plan ships in parallel in Wave 1.

Output: A `nextItemLabel` derivation in useRunControl (pure + reactive), a RunFilmstrip with larger thumbs + a next-item end cap + a reliable scrollbar, and a RunPreviewPair with a smaller On-screen pane.
</objective>
