<objective>
Replace the discrete slide-font-size multiplier with a real per-slide measure-and-fit at the SlideCanvas / canonical-stage level, and render the Audience + Confidence output windows on that same canonical 1280x720 stage so the fit computed once flows identically to the projector, the Run previews, and the thumbnails (WYSIWYG). This is the heart of R329.

Purpose: A projectionist gets slide text that auto-scales to fill the output display at projection distance, with no manual size control, while the configured font family/weight still render — and the Run-screen previews keep matching exactly what the projector shows.

Output: SlideCanvas driven by Plan 01's useSlideAutoFit (scoped rules read a measured --slide-fit-scale), the two output views wrapping SlideCanvas in a canonical stage via useContainScale, and an updated ARCHITECTURE.md note.

Depends on Plan 01 (useSlideAutoFit / useContainScale / REFERENCE_WIDTH/HEIGHT). Deliberately leaves the --slide-font-scale EMISSION in place (Plan 05 removes it after Plan 04 migrates the editor readers) so no reader is ever stranded on an undefined variable.
</objective>
