<objective>
Migrate the two editor-surface readers of the discrete `--slide-font-scale` multiplier off it, so the Slides grid card body and the Edit Slide drawer preview render at a fixed base size. These surfaces keep their own fixed-base mini-render (they are not the projector output and not Run previews, so they are deliberately out of the auto-fit scope), and dropping the multiplier here lets Plan 05 delete the variable and the sm/md/lg model without stranding a calc() on an undefined value.

Purpose: Part of R329's "remove the manual Size control" — the manual multiplier must stop influencing every render site. This plan handles the editor surfaces; Plan 03 handles SlideCanvas (output/previews); Plan 05 removes the setting + model.

Output: SlideCard.vue and EditSlideDrawer.vue with fixed-base scoped font sizes (family/weight preserved), plus their updated tests.

Independent of the auto-fit engine and the output views (disjoint files) — runs in Wave 1.
</objective>
