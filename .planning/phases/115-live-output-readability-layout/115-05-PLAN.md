<objective>
Retire the manual slide-font-size model now that auto-fit (Plans 01/03) owns text size and every reader (SlideCanvas in Plan 03; SlideCard + EditSlideDrawer in Plan 04) has migrated. Remove the Settings Size control, delete the fontScale field / SCALE_MAP / --slide-font-scale variable from the typography model, and sweep every remaining fontScale reference so the app type-checks and tests pass.

Purpose: Completes R329's "no manual font-size control" decision. Font FAMILY and WEIGHT stay exactly as today; only the size multiplier and its UI are gone.

Output: A trimmed slideTypography model + cssVarsFor, a fontScale-free OrgSettings type + defaults, a SettingsView with no Size control, and a green type-check + test suite after the fontScale sweep.

Runs last (Wave 3) so deleting the --slide-font-scale emission never strands a live reader. No Firestore migration: a stored fontScale on an existing org doc is silently ignored on read.
</objective>
