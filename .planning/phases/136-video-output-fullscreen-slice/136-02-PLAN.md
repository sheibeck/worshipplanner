|----------|-------------|
| unauthenticated web -> presentation route | `/present/video/:serviceId` is directly loadable; the router `beforeEach` guard is the UI access tier. |
| run-control window -> output window | The Video output receives the current-slide index over a same-origin BroadcastChannel; the output is receive-only and never posts state. |
