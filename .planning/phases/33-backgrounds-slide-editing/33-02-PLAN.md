## Flagged planner assumptions (edge probe, unresolved rows)

The specless edge probe classified **R051** and **R052** as `unclassified`. Per the never-auto-backstop
rule an unclassified row stays unresolved rather than being silently promoted. Both are surfaced here
as explicit assumptions rather than pretended-covered:

- **R051 (assumption):** its edge behaviour is defined by `33-UI-SPEC.md` §§2/3 and §11, not by the
  probe. The assumption being made is that "a slide enters edit mode only via the menu" is fully
  satisfied by (a) the menu existing on every card with a resolvable stored entry and (b) card click
  no longer opening the drawer — with no additional keyboard path to edit mode required beyond the
  native tab order into the trigger.
- **R052 (assumption):** its edge behaviour is defined by `33-UI-SPEC.md` §4's mode table. The
  assumption being made is that "separate drawers" is satisfied by one component with a `mode` prop
  (33-CONTEXT.md's explicit decision), not by two component files.

Both are recorded so a reviewer can overturn them cheaply, and neither is treated as probe-verified.
