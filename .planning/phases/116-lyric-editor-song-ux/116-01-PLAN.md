<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user click -> app navigation | A click on the read-only badge triggers a new-tab open; the navigation target must be derived from trusted app state, not the event. |
| app -> external site (songselect.ccli.com) | An outbound link to a third-party site is opened in a new browsing context. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-116-01 | Tampering | SlideGrid badge -> SlidesTab onEditInSongBadge | low | mitigate | Build the new-tab target from `props.selectedSlot.songId`/`songTitle` only (never from the DOM click event), preserving the T-33-24 property so the open cannot be redirected to an arbitrary song. |
| T-116-02 | Tampering | new-tab open (R333) + SongSelect anchor (R334) | low | mitigate | Pass `'noopener'` to `window.open` for the badge and reuse `rel="noopener"` on the SongSelect anchor so the opened page cannot reach `window.opener` (reverse tabnabbing). |
| T-116-03 | Information Disclosure | SongSelect href built from ccliNumber | low | accept | `ccliNumber` is a non-sensitive public catalog id already linked out from SongTable.vue in production; no new exposure. |
</threat_model>
