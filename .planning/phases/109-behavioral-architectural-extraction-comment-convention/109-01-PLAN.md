<objective>
Write the durable comment convention (R319): append a "## Comment Convention" section to
`.planning/codebase/CONVENTIONS.md` and add a one-line pointer from `CLAUDE.md`, so the standard the
v2.8 comments-as-specs work establishes holds for future work.

The convention states: comments stay short and explain only what code alone cannot convey at the point
of reading (non-obvious "why", gotchas, invariants); decision *rationale* lives in ADRs under
`docs/adr/` (Phase 108); behavioral/architectural "how it works" narration lives in `.planning/codebase/`
map docs (Phase 109); and both are cited from source by short pointers.

Purpose: without a written convention, the extraction done in Phases 108-109 erodes as new code
reintroduces long inline narration. Per 109-CONTEXT.md's "Convention doc home" decision this section is
co-located in CONVENTIONS.md with the behavior docs that now bear the load.
Output: a new CONVENTIONS.md section + a CLAUDE.md pointer.

This plan is independent of the R318 relocation plans (109-02..109-05): it touches only CONVENTIONS.md
(which has zero Bucket B entries mapped to it) and CLAUDE.md (untouched by the relocation plans), so it
runs in Wave 1 in parallel with 109-02.
</objective>
